# 時間割ツール（汎用版）

学校名・コース（学科）・学年・教室・時限・曜日を、**編集画面から自分で設定できる**時間割ツールです。
設定はサーバーに保存され、閲覧する人全員に同じ内容が届きます。

---

## 1. 構成ファイル

リポジトリの**直下**に置きます（`api` フォルダの中ではありません）。

| ファイル | 役割 |
|---|---|
| `index.html` | 閲覧用（トップ） |
| `edit.html` | 編集用（`/edit` でこれが開く） |
| `student.html` | 学生URL（`?s=`）・コースURL（`?w=`）・年度付きURL（`?y=`）用 |
| `manifest.json` / `manifest-edit.json` | ホーム画面アプリの定義（閲覧用／編集用） |
| `sw.js` | オフライン対応・高速起動 |
| `icon-*.png` / `apple-touch-icon*.png` | アプリのアイコン |
| `vercel.json` | URLの振り分け |
| `api/data.js` | データの読み書き（API） |

> **更新時の注意**：機能を修正したときは `index.html` `edit.html` `student.html` の3つを必ずセットで差し替えてください（中身のプログラムは共通です）。

---

## 2. 立ち上げ手順

### 2-1. GitHub にファイルを置く

1. 新しいリポジトリを作る（**Private 推奨**）。
2. 上記のファイルをすべてアップロードする。`api/data.js` は「Add file → Create new file」でファイル名に `api/data.js` と入力すると、`api` フォルダごと作成できる。

### 2-2. Vercel でプロジェクトを作る

1. Vercel で「Add New → Project」からリポジトリを選び、デプロイする。
2. **Storage** タブ → Marketplace → **Upstash（Redis）** で新しいデータベースを作成し、Connect する。
   - 他のプロジェクトのデータベースには接続しないこと（データが混ざります）。
3. **Settings → Environment Variables** に `EDIT_TOKEN` を追加する。
   - 値は編集画面のパスワード。**半角**で、16文字以上を推奨。
   - 適用先は **Production** にチェック。
4. **Deployments → 最新の行の「⋯」→ Redeploy** を実行する（環境変数は再デプロイで反映されます）。

### 2-3. 動作確認

ブラウザで `https://（あなたのURL）/api/data` を開き、`{"exists":false,"tokenSet":true}` と表示されれば準備完了です。

- `tokenSet:false` → `EDIT_TOKEN` が反映されていない（適用先とRedeployを確認）
- `404` → `api/data.js` の置き場所が違う
- `Redis(KV)の環境変数...` → Upstash が接続されていない

## 3. はじめの設定

1. `https://（あなたのURL）/edit` を開く。
2. パスワード（`EDIT_TOKEN` の値）を**半角**で入力する。
3. **セットアップ画面**が自動で開くので、上から順に入力する。

| 項目 | 内容 |
|---|---|
| 1. 学校の名前 | 正式名称と略称（略称は画面上部に表示されます） |
| 2. 学年と学期 | 何年制か（1〜6）、学期の呼び方（例：前期／後期、1学期／2学期） |
| 3. 曜日 | 授業のある曜日をクリックで選ぶ（土日も可） |
| 4. 時限と時刻 | 上から1限・2限…。時刻は表と印刷に出ます |
| 5. コース | 表示名・正式名称・色・URLキー・対象の学年 |
| 6. 教室 | 教室名と、特別教室かどうか |
| 7. 入力候補 | 科目名・講師名（任意。あとから足せます） |

「この内容で始める」を押すと保存され、時間割の編集ができるようになります。
設定はあとから **「設定」タブ**（編集画面のみ表示）でいつでも変更できます。

### コースの設定について

- **表示名**：画面のボタンに出る短い名前（例：調理）
- **正式名称**：印刷の見出しに出る名前（例：調理師科（2年制））
- **色**：時間割の見出しの色。選んだ色から、画面用と印刷用の配色が自動で作られます
- **URLキー**：配布用リンクに使う英字（例：`cook` →`?w=cook`）
- **対象の学年**：そのコースが存在する学年

> コース名は**あとから自由に変更できます**。時間割データはコースの「キー」で保存されているため、名前を変えても登録済みの授業はそのまま残ります。

---

## 4. URL の種類

| URL | 用途 |
|---|---|
| `/?y=2026` | 閲覧用（年度付き）。在校生に配る |
| `/?y=2026&w=cook` | コース専用（開くとそのコースが選択された状態） |
| `/?y=2026&w=cook&g=1` | 学年つきコース専用 |
| `/?s=（学生キー）` | 学生の個別時間割（本人にだけ渡す） |
| `/edit` | 編集画面（パスワードが必要） |

- 年度なしの `/` や、前年度のURLを開くと**案内画面**が出て、時間割は表示されません。
- 新年度を作ると前年度のURLは自動的に案内画面になります。新しいURLを配り直してください。
- コースURLの一覧は、編集画面のツールバー「**コースURL一覧**」から書き出せます。

---

## 5. 運用のポイント

- **バックアップ**：編集画面の「年度メニュー → 年度データをJSON書き出し」で、設定と時間割をまとめて保存できます。学期ごと・年度更新前に実行し、共有ドライブに保管してください。
- **年度更新**：「年度メニュー → 前年度をコピーして新年度」または「空の新年度を作成」。クラス時間割は引き継がれ、学生別は空になります。**元に戻せないので、必ず先にバックアップを取ってください。**
- **パスワード**：担当者の異動時や年度替わりに変更を。変更後は必ず Redeploy が必要です。
- **ホーム画面に追加**：スマホでアプリのように使えます。追加するときは、**時間割が表示されている状態**（年度付きURLや自分専用URLで開いた画面）で行ってください。
- **同時編集**：先に保存した人が優先されます。担当範囲や時間帯を分けるのがおすすめです。
